# PSPで「0 dB」にする方法 — 何の0 dBかが重要

対象：**実機確認済みのPSP-3000（04g）、Sound Volume Max Minimal alpha1、AVケーブルなし**。

## 1. コーデック制御値の「0 dB相当」を目指す操作

PSPの音量目盛りで、**最大から何段下か**を目安に設定します。**音を鳴らしたまま最大まで上げる必要はありません。** 最初は低音量・ミュート状態から操作してください。

| 経路 | 最大からの操作 | 04g内部計算上の目安 |
| --- | --- | --- |
| ヘッドホン | **3段下げる** | 0 dB相当 |
| 内蔵スピーカー | **5段下げる** | スピーカー補正を含め0 dB相当 |

※これは最大31段の音量テーブル上位7段を調査した結果から算出した目安。UI段数と音源側の音量は別です。04g以外への適用は未確認です。

計算の根拠：

- ヘッドホン：上位7段のうち**最大−3段**で元の引数 `−9`、PRXが `+9` → **0**。
- スピーカー：**最大−5段**で元の引数 `−8`、PRXが `+9` → **+1**。別途確認したスピーカー経路の1段相当の補正を差し引くと**0 dB相当**。
- 最大付近：制御引数上限 `+6`。ヘッドホンは公称+6、スピーカーは補正を含め公称+5という**コード上の参考値**。
- 純正ミュート値 `−127` は変えません。AVケーブル検出時は元の値をそのまま使用します。

## 2. 0 dBFS・0 dBu・音圧とは違う

**これらは別物です。**

| 表記 | 意味 | このPRXで保証できる？ |
| --- | --- | --- |
| 04gコーデックの「0 dB相当」 | 内部レジスタ・補正に基づく参考設定 | **計算上のみ** |
| **0 dBFS** | デジタル録音メーターのフルスケール | **いいえ** |
| **0 dBu** | アナログ信号の基準電圧（0.775 Vrms） | **いいえ** |
| dB SPL | 実際の音圧 | **いいえ** |

例えば以前のXMB選択音の測定では、AV接続時が約 **−15 dB（測定メーターの読み）**、増幅経路では約 **−10 dB（同じメーターの読み）** でした。これはその音・その測定経路のピークであり、出力全体の最大値ではありません。**0 dBFSまであと15 dB上げてよい**という意味ではありません。別の音源が先にクリップする可能性があります。

## 3. AV出力や録音機器のメーターを0 dBFSにしたい場合

このプラグインは **AV接続時に音量をブーストしない** 設計なので、AV出力を0 dBFSにする設定はありません。録音したい場合、機器の入力感度・ゲインを徐々に調整し、**実際の最大音量の場面でもピークが0 dBFSを超えず、歪まない範囲**に設定してください。0 dBFSぎりぎりではなく適切な余裕（ヘッドルーム）を取る方が安全です。

外部アンプにつなぐ時も、PSPの内部の「0 dB相当」が外部機器の基準レベルと一致すると考えないでください。続き：[外部機器の安全上の注意](EXTERNAL_AUDIO_SAFETY_ja.md)。
