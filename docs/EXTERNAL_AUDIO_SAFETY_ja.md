# スピーカー・ヘッドホン・外部機器に接続する時の注意

このPRXはPSPの内蔵スピーカーやヘッドホンに対する音量要求を増幅します。**入力が耐えられる音量、イヤホンの安全性、歪みの少なさを保証するものではありません。** 機器・聴覚の保護を優先してください。

## 内蔵スピーカー

- 最大音量は純正より大きくなる場合があります。長時間の最大音量は避ける。
- ビリつき・歪み・異音が出たら**すぐ下げる**。音量上限値を守っていても物理的な安全性は別です。
- 「最大−5段＝0 dB相当」は内部制御の計算であり、スピーカーが無歪み・安全であることを保証しません。

## ヘッドホン・イヤホン

- **初回再生やPRX切替時は耳から外した状態**でPSP音量を最小にする。音が確認できてから徐々に上げる。
- 感度の高いイヤホンは小さな段数でも大きな音になることがあります。痛み・耳鳴りを感じたら直ちに中止する。

## アクティブスピーカー・アンプ・ミキサー・録音機器

1. 機器の音量・入力ゲインを**最小**にする。できればアンプ側をミュート／電源OFFにしてから接続する。
2. 適合する**ライン入力**に接続する。スピーカー出力端子などの**出力同士を直結しない**。パッシブスピーカーをPSPのヘッドホン端子に直接つないで駆動しようとしない。
3. PSPを低音量で再生開始し、アンプ側／入力側を**少しずつ**上げる。音割れ、入力クリップ表示、極端な大音量が出れば直ちに下げる。
4. ケーブルを抜き差しする前に機器側を再度ミュート／音量最小にする。機器の電源投入・切断時のポップノイズに注意する。
5. PSPの**ヘッドホン端子→外部ライン入力**では、このPRXの増幅が入力を過大にする場合があります。必要ならPSP側の音量を下げるかPRXを無効にする。
6. **AVケーブル経由**では本PRXは純正音量要求を維持します。ただし測定済みの「−15 dB（メーターの読み）」はXMB選択音の一例であり、常にその値・常に安全という意味ではありません。

**0 dBの表記に注意：** コーデックの0 dB相当と、オーディオIFの0 dBFSピーク、アンプの0 dBu基準は異なります。数値が一致する前提で出力・入力を組まないでください。
