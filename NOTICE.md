# Attribution and provenance

The historical PSP **Audio Boost** plugin is attributed to **neur0n** (commonly listed for 6.2x–6.6x PSP custom firmware). Its original distribution license is listed as mixed/unspecified, and redistribution rights for the original code or executable have not been verified.

**Sound Volume Max Minimal** independently reimplements observed codec-volume behavior and external interface contracts. It does **not** include or patch the historical Audio Boost PRX, any binary delta, Sony firmware, or firmware dumps. Newly written code in this repository is offered under MIT (`LICENSE`); this does not claim ownership or relicensing of the original Audio Boost program.
