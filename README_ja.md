# Sound Volume Max — Minimal alpha1

PSP用CFW音量拡張PRX。長年使われてきたneur0n氏のAudio Boostと、実機で動作したSound Volume Max v1の**振る舞い**を参考に、新規に書いたソースです。元のPRX／バイナリパッチ／ファームウェアのダンプは配布しません。

**現在の状態：実機動作を確認したalpha版。** PSP-3000（04g）、6.61 / ARK-5と認識している環境で、ヘッドホン・内蔵スピーカー双方の音量増加を確認。AVケーブル接続時はXMB選択音が約 **−15 dB（使用したメーターでの読み）**で、抜き差し後も再現しました。ほかのPSPやFWでの動作は**未検証**です。

- [「0 dB」にする操作と、0 dBFSの違い](docs/VOLUME_AND_0DB_ja.md)
- [スピーカー／外部アンプ／録音機器の接続注意](docs/EXTERNAL_AUDIO_SAFETY_ja.md)
- [ビルド・実機確認状況](VALIDATION.md)

## できること

- **AVケーブルなし：** 音量引数を `min(元の値 + 9, +6)` にする。明示的なミュート `−127` は維持。
- **AVケーブルあり、またはAV状態不明：** 純正の音量要求を維持。AV音量を強制的に上げない。
- **フックは2か所：** ヘッドホンとスピーカーのSonyコーデック音量関数のみ。PCM、AV出力経路、ボタン、Sysconには介入しない。
- ファームウェア番号だけで拒否せず、関数のNIDを実行時に検索。ただし命令構造が想定外なら書き換えない。**全FW対応の保証ではない。**

## 0 dB相当へ合わせる（PSP-3000 04g、AVケーブルなし）

| 出力 | PSPの音量操作 | 意味 |
| --- | --- | --- |
| ヘッドホン | **最大から3段下げる** | 04gコーデックの計算上、およそ0 dB相当 |
| 本体スピーカー | **最大から5段下げる** | スピーカー側の1段補正を含め、およそ0 dB相当 |

**重要：これは内部のコーデック制御値における「0 dB相当」であり、デジタル録音のピーク0 dBFS、外部機器の0 dBu、実際の音圧を意味しません。** この設定でも音源によっては音量が大きすぎたり歪んだりします。詳しくは[0 dBの説明](docs/VOLUME_AND_0DB_ja.md)へ。

## PSPへの導入

1. 以前の動作済みPRXをバックアップし、ほかの音量変更PRXを無効にする。
2. ビルド済みの `SoundVolumeMax_minimal.prx` を `ms0:/SEPLUGINS/` にコピー。
3. ARK-5のプラグイン管理で、最初は**VSH（XMB）のみ**有効にする。
4. 完全電源OFFから起動する。初回はイヤホン・ヘッドホンを耳から外し、外部アンプの音量を最低にして、PSP側も小音量から始める。
5. ミュートと音量段数を確認。不具合時は無効化して電源を入れ直す。実行中のホットアンロードは推奨しない。

Flash0の書き込みは不要。AV接続時は純正音量のままになる仕様です。

## Ubuntu（WSL）ビルド

[PSPDEV](https://github.com/pspdev/pspdev)、`psp-cfw-sdk`、Python 3、makeを使用。

```bash
cd /mnt/c/Users/hujay/Downloads/SoundVolumeMax_GitHub_alpha1
bash build_wsl.sh
```

別の環境では展開先のリポジトリ直下で `bash build_wsl.sh` を実行してください。`SoundVolumeMax_minimal.prx` と `SoundVolumeMax_minimal.sha256` が生成されます。スクリプトには一般的な `NOT HARDWARE-TESTED` 表示が残っていますが、**今回記録したalpha1の実機成功と、今後再ビルドした別バイナリの検証状態は区別**してください。

## 検証・注意

- ソーステスト3項目PASS、PSPDEV GCC 15.2.0のC/アセンブリコンパイル、リンク、PRX生成が成功。
- 実機でスピーカー増幅、ヘッドホン増幅、AV接続時の純正相当レベル維持（抜き差し後も）を確認。
- 別の本体、6.60やそれ以前、POPS／ゲーム中などの組み合わせは未確認。FW番号固定判定を設けていないことと、あらゆるFWで動くことは別。
- コーデックの引数上限は、アナログ出力が無歪み・安全であることを保証しない。接続時は [外部機器の注意](docs/EXTERNAL_AUDIO_SAFETY_ja.md) を読むこと。
